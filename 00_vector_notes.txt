STL vector Example:
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;

    v.push_back(10);
    v.push_back(20);
    v.push_back(30);

    cout << "Elements: ";
    for (int x : v)
        cout << x << " ";

    return 0;
}
output:
Elements: 10 20 30

Important Functions:
v.push_back(40);   // Add element
v.pop_back();      // Remove last element
v.size();          // Number of elements
v.empty();         // Check empty
v.front();         // First element
v.back();          // Last element
v.clear();         // Remove all elements

vector = Dynamic Array (size can grow/shrink automatically).

----------------------------------------
Vector Declaration Examples:
vector<int> v;                  // Empty vector

vector<int> v(5);               // Size = 5, values = 0

vector<int> v(5, 10);           // Size = 5, all values = 10

vector<int> v = {1, 2, 3, 4};   // Initialize with values

vector<string> names;           // String vector

vector<char> ch = {'a', 'b'};   // Character vector

vector<vector<int>> mat;        // 2D vector


Syntax:vector<data_type> variable_name;
example:
vector<int> nums;
vector<float> marks;
vector<string> names;

For-Each Loop with vector:
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30, 40};

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}
Output:
10 20 30 40
Modify Elements:
for (int &x : v) {
    x += 5;
}

Note:

int x → Copies each element (read only).
int &x → Reference to original element (can modify).

vector Functions Example:
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    v.push_back(40);   // 10 20 30 40
    v.pop_back();      // 10 20 30

    cout << v.size() << endl;    // 3
    cout << v.front() << endl;   // 10
    cout << v.back() << endl;    // 30

    v.clear();                   // Remove all elements
    cout << v.empty();           // 1 (true)

    return 0;
}

MostUsed function:

| Function       | Example           | Work               |
| -------------- | ----------------- | ------------------ |
| `push_back(x)` | `v.push_back(5);` | Add last           |
| `pop_back()`   | `v.pop_back();`   | Remove last        |
| `size()`       | `v.size()`        | Number of elements |
| `empty()`      | `v.empty()`       | Check empty        |
| `front()`      | `v.front()`       | First element      |
| `back()`       | `v.back()`        | Last element       |
| `clear()`      | `v.clear()`       | Remove all         |
| `at(i)`        | `v.at(2)`         | Element at index   |
| `resize(n)`    | `v.resize(5)`     | Change size        |
